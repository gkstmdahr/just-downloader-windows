# just downloader for Windows

**Download any video!!** Just paste the video link to download it.
**모든 영상 다운!!** 영상 주소를 붙여 넣어서 간단하게 받으세요.

- Download / 받기: https://4dir.net/just-downloader/windows/
- Windows 10/11 · free · no install · 10 languages
- Contact / 문의: support@4dir.net

## How to run / 실행

1. Right-click the zip → Properties → check **Unblock** → OK
   (zip 우클릭 → 속성 → **차단 해제** 체크 → 확인)
2. Unzip anywhere and double-click **just downloader.vbs**
   (아무 곳에 풀고 **just downloader.vbs** 더블클릭)
3. If Windows SmartScreen appears: **More info** → **Run anyway**
   (윈도우 보안 창이 뜨면 **추가 정보** → **실행**)

Copy-protected (DRM) videos from paid streaming services can't be downloaded or recorded.
복제 방지(DRM)가 걸린 유료 스트리밍 영상은 받거나 녹화할 수 없습니다.
